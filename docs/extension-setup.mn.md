# AI Memory extension холбох

Эхлээд төслийн хавтсаа нээгээд шинэ хувилбарыг авна:

```bash
git pull --ff-only
uv sync --frozen
```

1. Chromium хөдөлгүүрийн 125 буюу түүнээс шинэ хувилбар шаардлагатай. Linux дээр Brave-ийн `brave://extensions` эсвэл Chrome/Chromium-ийн `chrome://extensions` хуудсыг нээнэ.
2. Developer mode → Load unpacked → `vendor/hstry/extension` хавтсыг сонгоно. Суулгасан бол Reload дарна. Extensions хуудаснаас AI Memory-ийн 32 үсэгтэй ID-г хуулна.
3. Дараах командын `YOUR_EXTENSION_ID`-г хуулсан ID-аар, `brave`-ийг шаардлагатай бол `chrome` эсвэл `chromium`-аар солино.

```bash
.venv/bin/ai-memory --db data/conversations.sqlite connect --extension-id YOUR_EXTENSION_ID --browser brave
```

4. Хөтчийн хэрэгслийн мөрөөс **AI Memory** дүрсийг дарна. Нээгдсэн жижиг цонхонд **Settings** рүү орж, `connection_file` замд буй файлыг сонгоно. Хөтөч локал програмыг хэрэгтэй үед өөрөө ажиллуулна. Тусдаа тохиргооны таб, нээлттэй терминал хэрэггүй. Файл сонгоход цонх хаагдвал **Settings → Paste connection file contents instead** дотор ижил JSON файлын агуулгыг оруулаад **Verify connection** дарна.
5. Хуучин v1 холболтын файл ажиллахгүй. Дээрх командаар v2 файл үүсгээд сонгоно. [Стандарт бус замын заавар](native-pairing.md).

## Цонхноос төсөл, яриа сонгох

Ашиглах үйлчилгээндээ энэ хөтчийн ижил профайлаар нэвтэрсэн байна. Өргөтгөл сайтын таб нээхгүй, сайтын хуудсанд товч нэмэхгүй.

1. **AI Memory** цонхонд ChatGPT, Claude эсвэл Gemini сонгоод **Load items** дарна. Энэ алхам нэр, таних дугаар зэрэг жагсаалтын мэдээлэл авна. Ярианы бичвэр татахгүй. Нэрээр хайж, төсөл эсвэл яриагаар шүүнэ. Gemini-д зөвхөн яриа харагдана.
2. Хэрэгтэй мөрүүдийг чагталж **Add to sync list** дарна. Ингэхэд зөвхөн сонгосон зүйлсийн таних дугаар тухайн бүртгэлтэй холбогдон хадгалагдана. Төсөл сонгосон бол доторх яриа бүрийг тусад нь нэмэх шаардлагагүй.
3. Тухайн үйлчилгээг идэвхжүүлээд **Sync now** дарна. Тэр үед л сонгосон ярианы бичвэр **локал архивт** орно. Хуваарьт цуглуулга идэвхтэй бол мөн адил хадгалсан жагсаалтыг ашиглана.
4. Хасах зүйл дээрээ **Remove** дарна. Жагсаалт хоосон бол юу ч цуглуулахгүй. Хасах нь өмнө архивласан бичвэр болон өгсөн зөвшөөрлийг өөрчлөхгүй.

Өмнөх хувилбарт хадгалсан ChatGPT-ийн тодорхой төсөл, ярианы сонголт хэвээр. Харин зөвхөн төрлөөр нь чагталсан хуучин тохиргоо цуглуулах эрх болохгүй. Жагсаалт дутуу бол үйлчилгээний хязгаарт хүрсэн эсвэл зарим хүсэлт амжилтгүй болсон байна. Дутуу жагсаалт өмнөх сонголтыг арилгахгүй. Нэвтрэлт танигдахгүй бол ижил профайл, бүртгэлээ шалгаад жагсаалтаа дахин ачаална.

**Sync now нь NotebookLM рүү илгээдэггүй.** Google-д өгөх бол `ai-memory preview ID`-аар бичвэрээ шалгаж, `ai-memory approve ID`, дараа нь `ai-memory sync` командыг тусад нь ажиллуулна. [Зөвшөөрлийн тайлбар](consent-backup.md).
