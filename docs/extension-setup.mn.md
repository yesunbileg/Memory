# AI Memory extension холбох

Эхлээд төслийн хавтсаа нээгээд шинэ хувилбарыг авна:

```bash
git pull --ff-only
uv sync --frozen
```

1. Chromium хөдөлгүүрийн 125 буюу түүнээс шинэ хувилбар шаардлагатай. Linux дээр Brave-ийн `brave://extensions` эсвэл Chrome/Chromium-ийн `chrome://extensions` хуудсыг нээнэ.
2. Developer mode → Load unpacked → `vendor/hstry/extension` хавтсыг сонгоно. Суулгасан бол Reload дарна. Extensions хуудаснаас AI Memory-ийн 32 үсэгтэй ID-г хуулна.
3. Дараах командын `YOUR_EXTENSION_ID`-г хуулсан ID-аар, `brave`-ийг шаардлагатай бол `chrome` эсвэл `chromium`-аар солино.

```bash
.venv/bin/ai-memory --db data/conversations.sqlite connect --extension-id YOUR_EXTENSION_ID --browser brave
```

4. Хөтчийн хэрэгслийн мөрөөс **AI Memory** дүрсийг дарна. Жижиг цонх архивыг таньж, **Local archive connected** гэж харуулна. Хөтөч локал програмыг хэрэгтэй үед нь өөрөө ажиллуулна.
5. Хуучин хувилбараар бүртгүүлсэн бөгөөд холбогдохгүй байвал дээрх командыг шинэ хувилбараар нэг удаа ажиллуулаад **Settings → Check connection** дарна. Өөр архив сонгохдоо **Settings → Connect a different archive manually** хэсгийг ашиглана. [Стандарт бус замын заавар](native-pairing.md).

## Сайтын жагсаалтаас сонгох

**Select all chats** нь тухайн workspace-ийн бүх зөвшөөрөгдсөн яриаг сонгоно. **Clear workspace selection** нь сонголтыг арилгах боловч архивыг устгахгүй.

1. Ижил хөтчөөр нэвтэрсэн ChatGPT, Claude эсвэл Gemini-ийн хуудсаа нээнэ. Хэрэгслийн мөрөөс **AI Memory → Settings → List mode**-ийг асаана. Сонгох нүднүүд сайтын хажуугийн жагсаалтад гарна. Өргөтгөл шинэ таб нээхгүй. Суулгах эсвэл шинэчлэхээс өмнө нээлттэй байсан сайтын хуудсаа нэг удаа дахин ачаална.
2. Төслөө чагталбал тэр даруй хадгалагдана. Төслийг задлах шаардлагагүй. Дараагийн цуглуулгад жагсаалтад харагдаагүй яриа ч хамрагдана. Gemini-д зөвхөн яриа сонгоно.
3. ChatGPT дээр **Recents** толгойн нүдийг чагталбал бүх энгийн Recent яриа хамрагдана. Дараа шинээр орсон Recent яриа ч хамрагдана. Зураастай нүд нь яриа сонгосон төсөл эсвэл Recents-д багтсаныг заана. Тусад нь чагталсан яриа бүлгийн сонголтыг арилгасан ч үлдэнэ. Яриаг давхар архивлахгүй.
4. Чагтыг авахад тухайн сонголт арилна. **List mode**-ийг унтраахад нүднүүд алга болох ч сонголт хэвээр үлдэнэ. Аль ч үйлдэл өмнө архивласан яриаг устгахгүй.
5. Хэрэгтэй үйлчилгээг идэвхжүүлээд **Sync now** дарахад бичвэр **локал архивт** орно. Хуваарьт цуглуулга асаалттай бол мөн ижил жагсаалтыг ашиглана. Чагтлах үйлдэл дангаараа цуглуулга эхлүүлэхгүй.

Шинэчлэхэд өмнөх бүртгэлдээ хадгалсан сонголтууд хэвээр байна. Таних боломжгүй бүртгэл эсвэл хоосон жагсаалтаас бүх яриаг автоматаар авахгүй.

Brave container бүрдээ sync хийх account-ийнхаа табыг нэвтэрсэн чигээр нь нээлттэй байлгаарай. Tab тус бүр дээр **List mode**-оор яриагаа сонгоод **Sync now**-г нэг удаа дарна. Явцын мөр шалгасан account, шалгасан болон хадгалсан ярианы тоог харуулна. Нэвтэрсэн таб нь олдохгүй account-ыг popup мэдээлнэ.

**Sync now** сонгосон чатыг SQLite архивт хадгална. NotebookLM холбогдсон, **Auto ON** үед зөвшөөрөлтэй чатуудыг Memory цааш автоматаар илгээнэ. **Auto OFF** үед NotebookLM рүү гараар синк хийхдээ `ai-memory sync` ажиллуулна. [Зөвшөөрлийн тайлбар](consent-backup.md)

Extension-ийн **Pause automatic sync** нь web capture-г түр зогсооно. NotebookLM-ийн арын нийтлэлийг тусад нь `mem` дотор `/auto off`-оор удирдана. Docs sync нь архивын Google нэвтрэлттэй цонхгүй Brave worker ашиглана.
