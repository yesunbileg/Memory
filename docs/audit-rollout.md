# AI Memory аудитын хэрэгжилт

## Хийсэн

- Claude-ийн нарийн PWA цонхны List mode-ийг зассан. Хоёр баталгаажсан аккаунтын тест чат NotebookLM-д хүрсэн. Эхний аккаунтын follow-up синк болсон. Хоёр дахь follow-up-ийг Claude хэрэглээний лимитээр буцаасан.
- Масклалтын бодлого v3 нь credential assignment, үйлчилгээний токен, URL доторх нууц үг, webhook, PEM/PGP key болон монгол нэршлүүдийг танина. Стандарт урт токены шалгалт URL, файлын зам, нийтэд нээлттэй PEM key-г алгасна. Масклалт тухайн талбар эсвэл мессеж дотор хийгдэнэ.
- 210 синтетик жишээтэй бие даасан корпус нэмсэн. 82 жишээ нь монгол эсвэл холимог. Корпусын тест 95%-ийн танилт, 0.1%-ийн хэт масклалтын босго, давтан боловсруулахад гаралт хэвээр байхыг шалгана.
- Бодит NotebookLM дээр 9 удирдлагатай эх шинэ бодлогоор солигдож бэлэн болсон. Эцсийн inventory шалгалтаар 0 sync ажил хүлээгдэж байв.
- Шинэ чат илгээх дараалалд автоматаар орно. Хуучин дарааллын нэг удаагийн миграци архивт тэмдэглэгдсэн өмнөх revocation-ийг хүндэтгэнэ. Browser capture болон локал hook нь `mem` хаалттай үед ажиллах worker-ийг сэрээнэ. Хоёр зэрэг capture, 10 минутын хүлээлт, sync дундуур нэмэгдсэн дараагийн ажлыг тестээр шалгасан.
- `memory_ask` NotebookLM руу явуулах асуултын танигдсан нууцыг масклана. Буцаах түүхэн агуулга `untrusted_history` тэмдэглэгээтэй.

## Үргэлжилж байгаа

- 12 MiB-ийн хугацаа бүх хэмжилтэд 2 секундэд багтаагүй. Нууц мөр нягт давтагдах өгөгдөл дээр нэмэлт оновчлол шаардлагатай.
- Хамгийн сүүлийн live rollout ажиллаж байсан `systemd` таймераар баталгаажсан. Capture-аас сэрсэн worker-ийн бодит туршилтыг таймергүй орчинд тусад нь хийх шаардлагатай.
- Browser extension-д баталгаажсан бүх аккаунтын бүх чат автоматаар цуглуулах default scope, ахисан түвшний хасах жагсаалт, 1,000+ чатын first-run шалгалт үлдсэн.
- Google session сэргээх мэдэгдэл, хуучин snapshot-ийн цэвэрлэгээ, provider болон NotebookLM canary, retrieval eval, `memory_open`, `forget`, CLI/TUI цомхотгол, нэг командын setup, эхлэх үеийн briefing болон бодит demo үлдсэн.

## Шийдвэр шаардлагатай

- NotebookLM ажиллахгүй үед FTS5 keyword fallback хэрэгтэй эсэх.
- Локал архивт танигдсан нууцыг бүрмөсөн масклах эсэх. Одоогийн v3 нь NotebookLM руу гарах агуулгыг масклана. Локал эх бичвэрийг хувиргах нь тусдаа миграци.
